# 🎨 Wallpaper Studio

**Wallpaper Studio** — это легковесное и стильное приложение для Windows, которое позволяет устанавливать любые фотографии или видео в качестве живых обоев вашего рабочего стола. Приложение поддерживает создание плейлистов, автоматическую смену видео по таймеру и работает в фоновом режиме.

## ✨ Возможности

- 🖼 **Статичные обои:** Установка изображений популярных форматов (PNG, JPG, BMP, WEBP).
- 🎬 **Живые видео-обои:** Воспроизведение видео прямо на рабочем столе позади ярлыков.
- 📋 **Плейлисты:** Добавление нескольких видеороликов в список воспроизведения.
- ⏱ **Авто-переключение:** Циклическая смена видео через заданный интервал времени (в секундах).
- 🔊 **Контроль звука:** Удобная регулировка громкости видео-обоев от 0% до 100%.
- 🚀 **Автозапуск:** Возможность включать приложение автоматически при старте Windows.
- 📥 **Работа в фоне:** Приложение аккуратно сворачивается в системный трей и не мешает работе.
- 🎨 **Современный UI:** Интерфейс выполнен в приятных темно-фиолетовых тонах с неоновыми градиентами.

## 📋 Системные требования

- **ОС:** Windows 10 / 11 (64-bit).
- **VLC Media Player:** Для корректной работы видео-обоев в системе **обязательно** должен быть установлен плеер VLC (64-bit). Вы можете скачать его с [официального сайта VideoLAN](https://www.videolan.org/vlc/).

## 🛠 Как пользоваться

1. **Для обычных фото:** В блоке «Статичные обои» нажмите *«Выбрать изображение...»*, найдите картинку и нажмите *«Установить как обои»*.
2. **Для видео:** В блоке «Видео-обои» нажмите *«➕ Добавить в плейлист»* и выберите один или несколько видеофайлов.
3. **Запуск живых обоев:** Нажмите кнопку *«▶ Запустить видео-обои»*. Для остановки используйте кнопку *«■ Остановить»*.
4. **Настройка слайдшоу:** Поставьте галочку на *«Авто-переключение»* и укажите интервал в секундах, чтобы видео менялись сами.
5. **Фоновый режим:** Нажмите кнопку *«Свернуть в трей»*. Чтобы полностью закрыть программу, нажмите правой кнопкой мыши по иконке приложения в трее Windows и выберите «Выход».

## 🚀 Разработка и сборка

Если вы хотите запустить проект из исходного кода или собрать `.exe` файл самостоятельно:

### Предварительные требования
Установите необходимые Python-библиотеки:
```bash
pip install PyQt5 python-vlc pyinstaller
```

### Сборка проекта
Для создания готового установщика или независимого запускаемого файла используйте PyInstaller:
```bash
pyinstaller --noconfirm --onedir --windowed --add-data "path/to/vlc;vlc" main.py
```
*(Примечание: Не забудьте включить необходимые DLL и плагины VLC в директорию сборки для корректной работы библиотеки python-vlc).*
